# Diagnostics

Open native Search menu → Diagnostics → Refresh. It shows actual Node process RSS and graphics device access. The daemon also accepts `diagnostics` over its existing local JSON control protocol. Acceleration remains unverified until genuine decoder/runtime evidence is available; device existence alone does not prove acceleration.

Errors retain readable messages and add stable categories for unsupported formats, restricted access, expired URLs, network, disk, decoder, permissions and timeouts. Permission or firmware issues need target logs. E_AUDIO_BUSY means another generic media player owns the audio source; stop that playback. E_CACHE_QUOTA means the development resource cap was reached. Lower quality or choose shorter permitted content. E_CLUSTER_UNVALIDATED means production cluster output is deliberately unavailable.

For local checks inspect reports/checks.json and each matching log. Baseline uses a fresh LF checkout to keep Unix shebangs valid; the untouched Windows upstream clones may contain CRLF. A skipped live extractor test is not a playback pass. Build prerequisites are reported by scripts/preflight.py.
